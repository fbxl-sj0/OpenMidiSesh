OpenSesh
===================

Portable Windows package

Extract the complete ZIP archive and run OpenSesh.exe. This package does not
install system services, require administrator privileges, or write normal
preferences into the application directory.

Preferences are stored for the current user in:

    %LOCALAPPDATA%/OpenSesh/settings.conf

The package includes the corresponding source archive, the GPL license,
third-party notices, and SHA-256 checksums. Keep those files with the program
when sharing the package.

This 0.9.0-dev package is an unsigned development build. See the project
releases page for current packages and checksums:

    https://github.com/fbxl-sj0/OpenMidiSesh/releases
